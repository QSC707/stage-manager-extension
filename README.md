# Stage Manager for Browser (网页版台前调度扩展)

将 macOS 台前调度 (Stage Manager) 的视觉与多任务管理体验带到 Chrome 与 Edge 浏览器中，以带有 **3D 景深的视觉缩略长廊** 彻底替代传统的顶部水平标签栏。

---

## 🌟 核心特性

- **左侧 3D 调度长廊 (Stage Strip)**：后台网页以微妙的 3D 透视倾角（`rotateY`）排列在侧边栏，鼠标悬停时平滑回正展开，苹果原生 Spring 弹簧动效。
- **实时视口缩略图 (Live Thumbnails)**：在切换网页或页面加载完成时自动截取页面微缩图，告别纯文字查找。
- **任务多标签编组 (Task Grouping)**：
  - 支持将相关的标签页拖拽合并到一个舞台中（呈现经典 macOS 卡片层叠效果 `Deck View`）。
  - 点击即可激活该组的工作流。
- **无缝流式切换**：点击长廊缩略卡片，瞬间平滑激活对应标签页。
- **开箱即用与极简快捷键**：
  - 点击扩展图标或按 `Alt + S` 呼出侧边栏。
  - 按 `Ctrl + K` / `Cmd + K` 快速全局搜索已打开的标签与域名。
  - 支持音频播放指示与一键静音控制。

## 🚀 安装与使用方法 (30秒完成)

### 第一步：在浏览器中加载扩展
1. 打开 **Google Chrome** 或 **Microsoft Edge** 浏览器。
2. 在地址栏输入并回车：
   - Chrome 用户：`chrome://extensions/`
   - Edge 用户：`edge://extensions/`
3. 开启页面右上角的 **「开发者模式 (Developer Mode)」** 开关。
4. 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」** 按钮。
5. 选中本项目文件夹：
   ```
   c:\Users\QsJul\Documents\antigravity\vibrant-meitner\stage-manager-extension
   ```
6. 扩展即刻加载成功！

---

### 第二步：将侧边栏停靠在左侧（还原 macOS 完美视觉）

- **在 Chrome 中**：
  1. 点击浏览器右上角扩展栏的 **Stage Manager** 图标打开侧边栏。
  2. 点击侧边栏顶部的设置（或在 Chrome 设置 -> 外观中），将侧边栏显示位置设置为 **「在左侧显示」**。
- **在 Edge 中**：
  1. Edge 浏览器自带左侧垂直侧边栏，点击 Stage Manager 图标即可在左侧展开。
  2. （可选推荐）在 Edge 标签栏右键选择「开启垂直标签」，并勾选「隐藏标题栏」，彻底告别顶部旧标签栏！

## ⌨️ 快捷操作指引

| 快捷键 / 操作 | 功能 |
|---|---|
| **Alt + S** | 呼出 / 收起台前调度侧边栏 |
| **Ctrl + K / Cmd + K** | 呼出搜索栏，实时过滤网页标题或网址 |
| **鼠标点击卡片** | 激活对应舞台/标签页 |
| **拖拽卡片到另一个卡片** | 将两个标签页合并为一个多任务舞台（层叠显示） |
| **悬停卡片右上角 `×`** | 快速关闭该网页或整个任务组 |
