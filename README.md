## ✨ 核心特性

- 🖥️ **调度长廊 (Stage Strip)**
  - **macOS 27" 视网膜超椭圆大圆角**：卡片窗口全面升级至 16px 大圆角与平滑曲率，搭配极细高光内描边与多层空间柔和投影，完美呈现 iMac 27" / Studio Display 级别的高级视觉质感。
  - **悬停即现红色关闭按钮**：鼠标悬停至任意长廊卡片或前台激活条时，右上角即刻浮现 macOS 标志性的经典红圈关闭按钮（#ff5f56），直接悬停微放大变亮，关闭操作迅捷自然。
  - **正向居中无偏斜视角**：彻底消除单侧水平倾斜角（零 yaw 偏转），卡片正向平行居中面对用户，悬停时平滑缩放放大并叠加自然深度阴影抬升，左右边距绝对等宽对称，不受任何切换左右的影响。
  - **原生极简透明浮窗与无背景标题**：标签页标题文字纯透明浮动呈现，去除深色衬底色块，搭配柔和文字投影，通透轻盈。
  - **紧凑高密布局**：间距缩减至 8px，卡片比例优化为 16:9，前台激活条精简至 32px，一屏阅览更多网页。
  - 1:1 单击即时流式穿梭切换，支持鼠标中键秒级关闭标签页。

- 📌 **顶部常驻固定标签页与目录集成区 (Top Pinned & Directory Bar)**
  - 物理级独立顶层常驻，长廊与目录无论如何滚动，固定标签页**绝对不被滑走**。
  - **顶部集成目录开关**：将目录开关直接集成在固定标签页区域的右侧，未固定标签时以极简单行呈现，一键开关缩略图大纲，并自动随目录位置智能同侧靠拢。
  - **激活态纯图标精简**：固定标签被激活后自动转为居中纯图标磁贴，绝不再反复截图刷新，阅读视线彻底无闪烁；未激活时平滑显示自适应微缩快照。
  - **声音状态提示与一键静音**：播放声音时左上角浮现呼吸波纹扬声器角标，静音状态显示红色静音图标，支持直接点击切换静音。
  - 通透轻盈的 macOS 磨砂微光玻璃底衬，完美自适应 Dark/Light 浅色与 `#3C3C3C` 深色主题。
  - 智能滚轮事件穿透：光标停在固定区时滚动滚轮自动透传滚动下方长廊。

- 🗺️ **VS Code 风格缩略图小地图 (Minimap Rail)**
  - **缩略图长度与滑块拖动区域 1:1 严格对齐**：目录视口滑块的显示长度与可拖拽行程严格受限于缩略图卡片总高度，无论是 3 个标签还是数十个标签，滑块绝不越界滑入空白区，长度与位置完美贴合。
  - 全局微缩大纲，即使打开几十个网页也能在侧边栏一目了然、极速漫游。
  - **120 FPS 丝滑拖拽**：纯 GPU 硬件合成变换与几何边界预计算，零延迟即时跟手。
  - **自由朝向**：点击顶部 `⇄` 按钮或在轨道空白处单击右键，可在**左侧**与**右侧**之间秒级切换，偏好自动持久化。
  - **悬浮卡片速览 (Glance Popover)**：鼠标滑过微缩项时，在视线自然侧展开磨砂玻璃大图速览。

- ⚡ **前台激活网页智能折叠 (Active Horizontal Bar)**
  - 正在浏览的激活网页**自动隐去缩略图**，收起为高度仅 38px 的极简纯标题横条。
  - Minimap 目录同步响应：激活项隐去微缩快照，呈现为紧凑的蓝色高亮发光胶囊条。
  - 极大节省垂直视野空间，当前激活位置一目了然，杜绝阅读时的图像刷新与闪烁干扰。

- 🖱️ **原生级右键卡片快捷菜单 (Context Menu)**
  - 在任意标签卡片（调度长廊、固定区四方格、小地图大纲）上**单击鼠标右键**即可唤出原生 macOS 磨砂玻璃快捷菜单：
    - 🪟 **原生分屏 (Split Screen)**：独家配备图标，调用浏览器单窗口原生标签分屏（Chromium Tabs Split View），绝不破坏或缩放系统级桌面窗口。
    - 📌 **固定标签 / 取消固定标签**：动态感知标签状态，一键将网页送入/移出顶部四方格固定区。
    - ↗️ **在新窗口打开**：迅速将目标标签独立为全新独立窗口。
    - 🚫 **关闭其他标签** / **关闭下方标签**：批量清理杂乱标签，根据位置智能可用性置灰保护。
    - 🔇 **将网站静音 / 取消网站静音**：一键控制媒体音量。

- 🛡️ **高稳定防幽灵截屏流水线与超清 Retina 离线缓存**
  - **超清 1024px 高清重采样**：升级至 1024px 宽度与 WebP 85% 高保真编码，在 2K/4K/Retina 高分屏下网页文字与排版清晰锐利，告别模糊。
  - **GPU 硬件级双三次插值**：采用 `imageSmoothingQuality: high` 与 `-webkit-optimize-contrast` 优化重采样算法。
  - **450ms 显存缓冲交换门禁**：彻底杜绝快速切换时截取到上一标签页画面的错位与黑帧现象。
  - **IndexedDB 持久化**：毫秒级离线提取缩略图，结合严格 URL 契约防脏读机制。
  - **实时运行诊断中心**：点击工具栏文档图标即可展开全景诊断日志，支持一键导出与缓存秒级清理。

## 🚀 安装与使用方法

### 方式一：下载 Release 压缩包（最便捷）
1. 在本仓库右侧 **[Releases](../../releases)** 中下载最新的 **`stage-manager-extension-v1.2.0.zip`**。
2. 解压到本地任意目录（例如文件夹 `stage-manager-extension`）。
3. 打开浏览器扩展管理页面：
   - **Chrome 用户**：在地址栏输入 `chrome://extensions/`
   - **Edge 用户**：在地址栏输入 `edge://extensions/`
4. 开启页面右上角的 **「开发者模式 (Developer Mode)」**。
5. 点击左上角的 **「加载已解压的扩展程序 (Load unpacked)」**，选择刚才解压出来的文件夹。
6. 点击浏览器工具栏的扩展拼图图标，将 **Stage Manager** 固定到工具栏即可开始使用！

### 方式二：克隆源码加载
```bash
git clone https://github.com/QSC707/stage-manager-extension.git
```
在浏览器扩展页面中加载已克隆的目录即可。

## ⌨️ 快捷操作与交互一览

| 操作 / 快捷键 | 功能说明 |
|---|---|
| **Alt + S** | 呼出 / 收起台前调度侧边栏 |
| **Ctrl + K / Cmd + K** | 快速展开/收起网页搜索栏，实时过滤标题或网址 |
| **左键单击卡片** | 即刻激活并平滑切换至对应网页（长廊中缩略图自动收折为横条） |
| **中键单击卡片** | 毫秒级直接关闭该标签页 |
| **拖拽 Minimap 滑块** | 120 FPS 零延迟平滑漫游调度长廊 |
| **点击 Minimap ⇄ 或右键单击轨道** | 自由切换目录在左侧或右侧显示 |
| **点击工具栏📋文档图标** | 展开/收起实时诊断日志抽屉，可查看日志或一键清理重置缓存 |
